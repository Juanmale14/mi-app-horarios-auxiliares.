📅 Generador de Horarios Semanales - Auxiliares de Conversación

Una herramienta web intuitiva y profesional diseñada para coordinadores de centros bilingües. Permite gestionar el claustro de auxiliares de conversación y generar cuadrantes horarios semanales (Lunes a Viernes) para cada grupo de alumnos, con opciones de exportación avanzada.

🚀 Características Principales

Gestión de Claustro: Añade auxiliares indicando su nombre y el cupo máximo de horas semanales.

Cuadrantes Semanales: Interfaz de cuadrícula completa de lunes a viernes (6 sesiones diarias) para cada grupo escolar.

Asignación Dinámica: Menús desplegables inteligentes que vinculan a los auxiliares con las sesiones de clase.

Exportación Profesional (PDF):

Por Grupos: Genera un PDF donde cada grupo ocupa una página independiente con su horario semanal.

Por Auxiliares: Genera un PDF individualizado para cada auxiliar con su ruta de grupos y horas asignadas.

Exportación a Excel: Descarga un libro de Excel con múltiples hojas (una por grupo) para una gestión administrativa más profunda.

Diseño Adaptativo: Totalmente funcional en dispositivos móviles, tablets y ordenadores.

🛠️ Tecnologías Utilizadas

HTML5 & CSS3: Estructura y diseño con degradados modernos y tipografía legible.

JavaScript (Vanilla): Lógica de la aplicación y gestión de estados.

jsPDF: Para la generación de documentos PDF dinámicos.

jsPDF-AutoTable: Para el formateo profesional de tablas en los PDF.

SheetJS (XLSX): Para la creación y descarga de archivos Excel.

📦 Instalación y Uso

No requiere servidor ni base de datos. Es una aplicación client-side pura.

Clona este repositorio:

git clone [https://github.com/tu-usuario/nombre-repo.git](https://github.com/tu-usuario/nombre-repo.git)


Abre el archivo index.html en cualquier navegador web moderno.

¡Empieza a organizar tus horarios!

📖 Guía de Usuario

Pestaña Claustro: Introduce los nombres de los auxiliares. Puedes usar el botón "Cargar Ejemplo" para ver cómo funciona el sistema de inmediato.

Pestaña Horarios: Selecciona el auxiliar correspondiente para cada sesión en los cuadrantes de los grupos.

Pestaña Exportar: Elige el formato que necesites para imprimir o distribuir por correo electrónico/WhatsApp.
